# Depth Media

A parallax depth image component. Splits a single image URL into three visual layers — blurry background, mid-shadow, and a sharp elevated foreground — that shift at different rates when inside a [Tilt](/docs/components/tilt-card) card. The result is a convincing 3D depth illusion without any depth-map data.

## Installation

<InstallSnippet registryUrl='https://prismaui.com/components/depth-media.json' />

```tsx

import { Tilt } from '@/components/ui/tilt';
```

## Standalone (no Tilt)

`DepthMedia` renders the depth layers even without a `Tilt` parent — the visual depth cues (blur, shadow, vignette) are still present, just without the interactive parallax.

## Props

| Prop             | Type     | Default | Description                                              |
| ---------------- | -------- | ------- | -------------------------------------------------------- |
| `src`            | `string` | —       | Image URL passed to all parallax layers.                 |
| `alt`            | `string` | `''`    | Accessible alt text for the foreground image.            |
| `className`      | `string` | —       | Additional CSS classes for the container.                |
| `depthIntensity` | `number` | `8`     | Parallax multiplier — higher values increase layer shift. |
