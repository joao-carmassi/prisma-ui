# Tilt Card

A 3D tilt wrapper that applies a perspective tilt effect on mouse movement. Inspired by [Motion Primitives' Tilt](https://motion-primitives.com/docs/tilt). Wrap any Card or element for interactive depth.

## Installation

<InstallSnippet registryUrl='https://prismaui.com/components/tilt.json' />

## Import

```tsx
import { Tilt } from '@/components/ui/tilt';
```

## Props

| Prop             | Type              | Default | Description                    |
| ---------------- | ----------------- | ------- | ------------------------------ |
| `children`       | `React.ReactNode` | —       | Content to tilt.               |
| `className`      | `string`          | —       | Additional CSS classes.        |
| `style`          | `MotionStyle`     | —       | Motion style overrides.        |
| `rotationFactor` | `number`          | `15`    | Max rotation angle in degrees. |
| `isReverse`      | `boolean`         | `false` | Reverse the tilt direction.    |
| `springOptions`  | `SpringOptions`   | —       | Spring animation config.       |

## DepthMedia

A companion component that places an image inside the Tilt card and gives it real parallax depth. A blurry, desaturated background layer and a sharp foreground layer shift at different rates as the card tilts, creating the illusion that the image has volume.

### Installation

<InstallSnippet registryUrl='https://prismaui.com/components/depth-media.json' />

### Import

```tsx
import { DepthMedia } from '@/components/ui/depth-media';
```

### Preview

Place `DepthMedia` inside a **positioned container** (e.g. `relative h-48`) within a Tilt card and hover to see the parallax layers in action.

<ComponentPreview>
  <Tilt rotationFactor={15} springOptions={{ stiffness: 300, damping: 20 }}>
    <Card className='w-72 overflow-hidden'>
      <div className='relative h-48'>
        <DepthMedia
          src='https://picsum.photos/288/192'
          alt='Mountain landscape'
        />
      </div>
      <CardHeader>
        <CardTitle>Depth Media</CardTitle>
        <CardDescription>Hover to feel the parallax depth.</CardDescription>
      </CardHeader>
    </Card>
  </Tilt>
</ComponentPreview>

```tsx
<Tilt rotationFactor={15} springOptions={{ stiffness: 300, damping: 20 }}>
  <Card className='w-72 overflow-hidden'>
    <div className='relative h-48'>
```

### DepthMedia Props

| Prop             | Type     | Default | Description                                               |
| ---------------- | -------- | ------- | --------------------------------------------------------- |
| `src`            | `string` | —       | Image URL passed to all parallax layers.                  |
| `alt`            | `string` | `''`    | Accessible alt text for the foreground image.             |
| `className`      | `string` | —       | Additional CSS classes for the container.                 |
| `depthIntensity` | `number` | `8`     | Parallax multiplier — higher values increase layer shift. |
