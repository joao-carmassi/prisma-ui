# Border Glow

A card wrapper that emits a colorful gradient glow along its border when the pointer approaches any edge. Inspired by [React Bits' Border Glow](https://www.reactbits.dev/components/border-glow). The glow is directional — it follows the exact cursor position along the border — and fades out as the pointer moves toward the card center.

## Installation

<InstallSnippet registryUrl='https://prismaui.com/components/border-glow.json' />

## Import

```tsx
import { BorderGlow } from '@/components/ui/border-glow';
```

## Edge Sensitivity

`edgeSensitivity` (px) controls how far from the edge the glow activates.

<ComponentPreview className='gap-6 items-start flex-wrap'>
  <BorderGlow className='w-60 p-5' edgeSensitivity={10}>
    <p className='text-sm font-medium'>Tight (10 px)</p>
    <p className='mt-1 text-xs text-muted-foreground'>Glow only on the edge itself</p>
  </BorderGlow>
  <BorderGlow className='w-60 p-5' edgeSensitivity={80}>
    <p className='text-sm font-medium'>Wide (80 px)</p>
    <p className='mt-1 text-xs text-muted-foreground'>Glow activates anywhere near edges</p>
  </BorderGlow>
</ComponentPreview>

```tsx
{/* Tight — only right on the border */}
<BorderGlow edgeSensitivity={10}>...</BorderGlow>

{/* Wide — activates well before reaching the edge */}
<BorderGlow edgeSensitivity={80}>...</BorderGlow>
```

## Props

| Prop              | Type                        | Default                              | Description                                               |
| ----------------- | --------------------------- | ------------------------------------ | --------------------------------------------------------- |
| `children`        | `React.ReactNode`           | —                                    | Content rendered inside the card.                         |
| `className`       | `string`                    | —                                    | Additional CSS classes for the outer wrapper.             |
| `edgeSensitivity` | `number`                    | `30`                                 | Distance in px from edge where glow activates.            |
| `glowColors`      | `[string, string, string]`  | `['#c084fc','#f472b6','#38bdf8']`    | Three hex colors for the gradient.                        |
| `backgroundColor` | `string`                    | `'hsl(var(--card))'`                 | Background color of the inner card area.                  |
| `borderRadius`    | `number`                    | `12`                                 | Corner radius in pixels.                                  |
| `glowRadius`      | `number`                    | `40`                                 | Outer glow spread in pixels beyond the card.              |
| `glowIntensity`   | `number`                    | `1`                                  | Glow brightness multiplier (0.1 – 3.0).                   |
| `coneSpread`      | `number`                    | `100`                                | Gradient radius controlling glow width along the border.  |
| `animated`        | `boolean`                   | `false`                              | Play a one-shot border sweep animation on mount.          |
