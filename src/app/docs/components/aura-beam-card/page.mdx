# Aura Beam

An ambient glow wrapper that rotates a conic-gradient around any element, inspired by [daisyUI's Aura](https://daisyui.com/components/aura/). Unlike `BorderBeam`, which projects a sharp laser along the inner border, `AuraBeam` wraps the component from outside and produces a soft, diffuse halo effect with blurred glow layers behind it.

## Installation

<InstallSnippet registryUrl='https://prismaui.com/components/aura-beam.json' />

## Import

```tsx
import { AuraBeam } from '@/components/ui/aura-beam';
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from '@/components/ui/card';
```

## CSS Custom Properties

Override these CSS variables on the `AuraBeam` element to tweak the effect without extra classes:

| Variable          | Default               | Description                        |
| ----------------- | --------------------- | ---------------------------------- |
| `--aura-padding`  | `2px`                 | Thickness of the glow border       |
| `--aura-radius`   | `0.75rem`             | Corner radius (match your card)    |
| `--aura-duration` | `6s`                  | Full rotation duration             |
| `--aura-color`    | `hsl(var(--primary))` | Base color for the default variant |

```tsx
<AuraBeam
  style={
    { '--aura-padding': '3px', '--aura-duration': '8s' } as React.CSSProperties
  }
>
  <Card className='rounded-[inherit] border bg-background'>...</Card>
</AuraBeam>
```

## Modifier classes

| Class               | Effect                                               |
| ------------------- | ---------------------------------------------------- |
| `aura-beam-rainbow` | Full-spectrum rainbow conic gradient                 |
| `aura-beam-holo`    | Holographic cyan / violet / pink palette             |
| `aura-beam-glow`    | Stronger blur layers for a more intense ambient glow |

## Props

| Prop        | Type                  | Default | Description                                        |
| ----------- | --------------------- | ------- | -------------------------------------------------- |
| `children`  | `React.ReactNode`     | —       | Content wrapped by the aura                        |
| `className` | `string`              | —       | Additional CSS classes (use modifier classes here) |
| `style`     | `React.CSSProperties` | —       | Override CSS custom properties inline              |
